# GnOuGo Homebrew tap

## ProxyCopilot standalone server

Install the local VS Code Chat/Agent proxy on Apple Silicon or Intel Macs running
macOS Monterey 12 or later:

```bash
brew install gnougo/tap/gnougo-proxy-copilot
gnougo-proxy-copilot
```

Open http://127.0.0.1:5087/ui/. No .NET SDK/runtime or desktop application is
required. The server runs in the foreground and accepts loopback connections only;
stop it with Ctrl+C. Installation does not start a background service.

If Homebrew asks for trust, review [the formula](Formula/gnougo-proxy-copilot.rb)
and run `brew trust --formula gnougo/tap/gnougo-proxy-copilot`, then retry.

Configure providers using `ProxyCopilot__Providers__...` environment variables;
see the [server documentation](https://github.com/GnouGo/GnouGo/blob/main/src/GnOuGo.ProxyCopilot.Server/README.md#configure-providers).
Examples are installed in `$(brew --prefix gnougo-proxy-copilot)/libexec/examples`.
Do not put private settings or credentials in the Cellar: upgrades replace the
versioned installation directory.

```bash
brew update
brew upgrade gnougo/tap/gnougo-proxy-copilot
brew uninstall gnougo-proxy-copilot
```

## GnOuGo desktop application

```bash
brew install --cask gnougo/tap/gnougo
```

The desktop cask is separate from the ProxyCopilot formula.

## Maintenance

Stable releases in [GnouGo/GnouGo](https://github.com/GnouGo/GnouGo/releases)
update both packages through its release workflow. The ProxyCopilot formula is
generated by `scripts/update-proxy-copilot-homebrew.py` in that repository from
the release's ARM64 and x64 archives and their SHA-256 checksums. Make permanent
formula changes in that generator so future releases retain them.

Tap CI installs the formula and checks its loopback HTTP server and dashboard on
both Apple Silicon and Intel macOS runners when the formula changes.
